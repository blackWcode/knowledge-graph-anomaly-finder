03 / THE METHOD

Transparent by design.

No inferred relationships. No hidden confidence score. Every alert traces back to a specific, inspectable rule.

01

Find the source

Does the event contain a source and target? If either is missing, flag malformed input.

02

Look up allowed edges

Does the source appear in the graph? If not, flag an unknown source. Otherwise retrieve its connected_to list.

03

Explain the result

If the target is on the list, accept. Otherwise, flag the unexpected connection and show what was expected.

What makes an explanation useful?

In this prototype, an explanation is a traceable statement about the rule: this source can connect to these targets, but the observed target was not among them.

That demonstrates a structural mismatch, not proof of a physical fault or malicious activity.
