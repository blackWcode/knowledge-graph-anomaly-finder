01 / THE QUESTION

What happens when an observed
connection breaks the expected structure?

A dictionary-backed directed graph stores explicitly permitted relationships. A simulated telemetry stream is audited against those edges; violations are visible, inspectable, and explainable.

01 — MODEL THE SYSTEM

Describe the topology

Represent a sensor, valve, tank and outlet, together with the allowed directed connections between them.

02 — AUDIT EVENTS

Inspect the stream

Check source and target fields for each event, using the graph as the reference for expected behaviour.

03 — EXPLAIN THE ALERT

Expose the mismatch

Show which connection was observed and the specific list of targets allowed by the source node.
