# knowledge-graph-anomaly-finder
The Idea: Build a small dictionary- or list-based graph in Python that represents relationships (e.g., Sensor A connects to Valve B; Valve B links to Tank C). Use loops (or simple graph-traversal algorithms) to check incoming state updates against expected topological paths. If a state violates a graph relationship rule, flag it as an anomaly.

Why it connects: It introduces Knowledge Graph structures and relational reasoning, helping you practice querying structured symbolic data programmatically to audit system behaviour.
